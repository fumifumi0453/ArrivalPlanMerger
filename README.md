# ArrivalPlanMerger

受信したExcelから入荷予定ファイルを自動更新するツールです。

1. Excel を CSV にする
2. 必要な列だけに加工する
3. 必要な行だけ抜き出す（`RowFilters` の条件をすべて満たす行）
4. オーダー番号でファイルを分ける
5. オーダー別フォルダに移動する
6. 各フォルダの入荷予定ファイル（Excel）にマージする（キー列が同じ行は上書き、無ければ追加）
   - 最後の列「最終更新日」に、追加・変更した日時を入れる
   - 同じ名前の CSV 版入荷予定ファイルがあれば、初回にその内容を引き継ぐ
7. マージに使った新しいファイルをオールドフォルダ（既定: 各オーダーフォルダ内の `old`）に移動する

## CSharp/ (.NET 8 コンソールアプリ)

- Excel 不要（ClosedXML で直接読み込み）
- 設定は `settings.json`
- `settings.json` のパスは、exe を実行したときのカレントフォルダからの相対パスでも指定できます
  （タスクスケジューラで実行する場合は「開始（オプション）」にフォルダを指定してください）
- 発行（フォルダー）すると、ランタイム不要の単一 exe（win-x64）ができます
- 実行先には `ArrivalPlanMerger.exe` と `settings.json` をコピー

## PowerShell/ (Windows PowerShell 5.1)

- Excel 本体が必要（COM で CSV 保存）
- 設定はスクリプト冒頭の `$Config`
- `実行.bat` をダブルクリック、またはタスクスケジューラで `実行.bat /nopause`

## 共通

- 分割ファイルの CSV は Shift_JIS / CRLF
- マージ前に `入荷予定.xlsx.bak` を作成
- 入荷予定ファイルを Excel で開いたままだと保存できずエラーになります
- ログは `logs\yyyyMMdd.log`
